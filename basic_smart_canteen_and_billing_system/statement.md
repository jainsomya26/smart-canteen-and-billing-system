# Project Statement

## Problem Statement

Managing canteen menu items, customer orders, and bills manually can be time-consuming and may lead to calculation or record-keeping errors.

## Objective

Build a simple Python-based Smart Canteen and Billing System that manages menu items, orders, billing, and basic sales information.

## Scope

The project supports menu management, item searching, order placement, bill generation, and sales reporting through a terminal interface.

## Users

The system is intended for a small canteen operator or cashier.

## Storage

All records are stored locally in text files inside the `data` folder.

## Excluded

The project does not use a GUI, web server, online payment gateway, external database, or cloud service.
